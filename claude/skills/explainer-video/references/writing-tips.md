# スライドと台本の書き方のコツ

実際に動画を作って、見る人がつまずいた点・見た目が崩れた点から得たコツをまとめたもの。
SKILL.md の手順 3〜4 (スライドと台本を書く) の前に読む。

## 目次

1. 構成の目安
2. スライド (slides.md)
3. 台本 (narration/NN.txt)
4. 字幕の辞書 (caption-dict.tsv)
5. よくある失敗と確認方法

## 1. 構成の目安

- 5 分前後・10〜12 枚が見やすい。1 枚あたりの読み上げは 20〜35 秒。
- 流れの基本形: 概要 → 全体像 (図) → 鍵となる概念 → 部品ごとの説明 → 使い方・注意点 → まとめ。
- 目的は「細部の網羅」ではなく「メンタルモデルを作ること」。全体像のスライドは早めに出し、
  後のスライドでは「全体像のどこの話か」に触れると迷子にならない。
- 依頼者がとくに理解したい箇所 (例: 「nvim-cmp の補完を使いこなしたい」) には 1〜2 枚多めに割く。

## 2. スライド (slides.md)

- `assets/slides-template.md` をコピーして使う。テーマ (gruvbox 風の配色、コードの色分け) が入っている。
- **図は ASCII 文字 (`+ - | > < v ^`) だけで描く。** 罫線文字 (┌─┐) は日本語フォントで幅がずれ、
  `▶` などは絵文字として描画されて崩れる。図の中のラベルも英数字にすると幅がずれない。
- コードブロックは 12 行程度まで。長いコードは要所だけを抜き出し、省略は `...` で示す。
- 1 枚に詰め込みすぎない。箇条書きは 3〜5 個、表は 5 行程度まで。
- 最後のスライドには `<!-- _footer: 音声: {{VOICE_CREDIT}} -->` を残す。VOICEVOX の利用規約で
  クレジット表記が必要なため。build.sh が実際の音声エンジン名に置き換える。
- 画像は `<work_dir>/images/` に置き、`![](images/x.png)` と相対パスで書く。外部 URL の画像、絶対パス、
  `..` で作業ディレクトリの外を指す画像、CSS の `@import` / `url(https://...)` は build.sh が止める。
  引用元の URL は本文かリンク (`[出典](https://...)`) として書く (表示されるだけで、通信は起きない)。

## 3. 台本 (narration/NN.txt)

- ファイル名はスライドの番号に合わせる (1 枚目 → `01.txt`)。番号とスライドがずれると、
  別のスライドに別の説明が付いてしまう。
- **英語の語はカタカナで書く。** 音声エンジンは英単語を正しく読めないことが多い。
  例: `Claude Code` → クロードコード、`nvim-cmp` → エヌヴィムシーエムピー、`is_available` → イズアベイラブル。
- 字幕にはカタカナのまま表示されるので、英語に戻す対応を `caption-dict.tsv` に書く (次節)。
- 文は「。」で終える。字幕は 1 文ずつ表示され、38 文字を超える文は「、」で区切られる。
  読点の無い長い文は字幕が 2 行になるので、適度に「、」を入れる。
- 話し言葉で書く。スライドの文字をそのまま読むのではなく、スライドの図や表を「指さしながら」説明する。
- 数字や記号 (`%3`、`--clear`) は読み方をカタカナや言葉で書く (「パーセント 3」「クリアオプション」)。

## 4. 字幕の辞書 (caption-dict.tsv)

- 形式: `読み<TAB>字幕での表示`。`#` で始まる行はコメント。
- 共通の辞書 `assets/caption-dict.tsv` (Claude Code、Neovim、JSON など) に、
  作業ディレクトリの `caption-dict.tsv` が上書きで足される。題材固有の語は作業ディレクトリ側に書く。
- 長い読みから順に置換される。「マイコンフィグ点ルア → myconfig.lua」と「ルア → Lua」は両方書いてよい。
- 短すぎる読み (2〜3 文字) は、別の語の一部を誤って置換しやすい。前後の文字も含めて登録する
  (例: 「ピー」ではなく「ピーで → p で」)。
- 日本語として自然なカタカナ語 (コミット、ファイル、バッファ) は登録しない。

## 5. よくある失敗と確認方法

| 症状 | 原因 | 対処 |
|---|---|---|
| 図の枠線がずれる | 罫線文字・絵文字 | ASCII 文字だけで描き直す |
| コードの文字列が読めない | テーマの配色が無い | 雛形の `style` をそのまま使う |
| 字幕がカタカナ | 辞書に無い | 作業ディレクトリの caption-dict.tsv に追加 |
| 字幕が 2 行で窮屈 | 読点の無い長い文 | 台本に「、」を入れる |
| 別のスライドに別の説明 | 台本の番号ずれ | スライド枚数と narration の数を合わせる |

確認は build.sh の出力に出る `longest caption` の画像と、図・コードのあるスライドの
`build/f_<スライド番号>_01.png` を Read で見る。
